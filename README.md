# Kammer v3

Agentic website manager for real estate agents and any business, at about half the price of luxury agencies. Includes a launch kit: logo, leather stationery, Notion hubs and business tools.

Design: gloss black, neon yellow `#E8FF1A`, electric blue `#2B5BFF`, white.

- `index.html` landing and pricing
- `kit.html` launch kit overview
- `stationery.html` editable, printable leather letterhead, card and envelope
- `kit/notion/` importable Notion hubs
- `assets/` logo, mark, stylesheet

Static site. Open `index.html` or run `python3 -m http.server`.
